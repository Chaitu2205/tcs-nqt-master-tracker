# 🚀 TCS NQT Master Tracker

A modern **Progressive Web App (PWA)** designed to help students prepare for the **TCS National Qualifier Test (NQT)** by tracking their daily progress, coding practice, aptitude preparation, interview readiness, and study goals.

🌐 **Live Demo:** https://tcs-nqt-master-tracker.vercel.app

---

## 📖 About

While preparing for TCS NQT, I searched for a tracker that matched my study workflow but couldn't find one that fit my needs. So I decided to build my own.

This project was developed with the help of **ChatGPT** and **Claude** as AI development assistants. They helped me generate ideas, understand concepts, debug issues, and accelerate development, while I tested, customized, and deployed the application.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Chaitu2205/tcs-nqt-master-tracker.git
```

Open the project folder

```bash
cd tcs-nqt-master-tracker
```

Run

Simply open **index.html** in your browser.

Or deploy using **Vercel**.
